# 🛡️ Giai Đoạn 5: Production, Bảo Mật, Private AI Stack & MLOps

> *"Trong môi trường tài chính - ngân hàng, việc đưa AI vào vận hành đòi hỏi 3 yếu tố cốt lõi: Bảo mật dữ liệu (Private), Phòng thủ tấn công (Security/Guardrails) và Tính có thể giải thích (Explainable AI)."* — Góc nhìn chuyên gia từ **Mì AI**

## 🎯 Mục Tiêu Giai Đoạn 5
1. **Triển khai Private AI Stack (Mô hình chạy nội bộ 100% Offline):**
   * Chạy mô hình ngôn ngữ mã nguồn mở (Qwen 2.5, Llama 3.2) bằng Ollama trên GPU RTX 3060.
   * Kết nối giao diện người dùng Open WebUI cao cấp bằng Docker Compose.
2. **Phòng thủ Tấn Công Prompt Injection & Rò Rỉ Dữ Liệu:**
   * Hiểu về Direct Injection (Jailbreak, bypass rules) và Indirect Injection (đầu độc tài liệu RAG).
   * Viết lớp Guardrails kiểm duyệt an ninh đầu vào (Input Sanitization).
3. **Hoàn thành Đồ Án Capstone Tốt Nghiệp:**
   * Tích hợp toàn bộ kiến thức từ Giai đoạn 1 đến 5 thành sản phẩm thực tế có thể đưa vào CV / Portfolio xin việc.
